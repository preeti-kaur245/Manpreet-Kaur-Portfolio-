## 🌟 Core Philosophy

### **NOTICE. QUESTION. BUILD.**

1. **Observe**: Notice daily friction in human workflows.
2. **Question**: Challenge why legacy systems are accepted as normal.
3. **Understand**: Empathize deeply with users under real-world pressure.
4. **Design**: Create clear, minimal mental models.
5. **Build**: Engineer functional, high-performance products.
6. **Test & Improve**: Iterate based on live feedback and real-world usage.

## 🚀 Featured Projects & Interactive Prototypes

- **RIMTify**: Smart attendance platform designed around the actual workflow of faculty members. Includes 1-tap toggling, real-time presence counters, session selectors, and roster search.
- **Fusion Fest**: Automated e-certificate retrieval and verification platform. Eliminates manual post-event distribution bottlenecks.
- **ResumeForge**: AI-assisted resume building concept with real-time ATS optimization, contextual questioning, and synchronized live canvas preview.
- **RIMT Mentor AI**: Voice and conversational learning tutor (*"Learn Smarter with Preeti"*) exploring active pedagogy (`Explain → Ask → Guide → Correct → Teach`).
- **RAFTAAR Collective**: Multidisciplinary student collective bridging AI, Design, Code, Media, Events, and Innovation.

## ⚡ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/preeti-kaur245/Manpreet-Kaur-Portfolio-.git

# Navigate to project directory
cd Manpreet-Kaur-Portfolio-

# Install dependencies
npm install

# Start local development server
npm run dev
```
